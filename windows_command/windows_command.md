# Windows Commands List
### Open Windows Command Prompt (CMD) or Windows PowerShell 
# --------------> Commands List <---------------

## 1. dir - লিখে Enter দিলে সেখানে কতগুলো Folder আছে দেখাবে।

 ## 2. cls -Enter দিলে সব ক্লিয়ার হয়ে যাবে। 

 ## 3. আপনি যদি কোনো Folder এ যেতে চান তাহলে আগে (dir) দিয়ে দেখে নিবেন তখন সব Folder দেখাবে . এরপর যে Folder এ যেতে চান তার জন্য ব্যবহার করবেন- cd  < folder name > 
## (যে Folder এ যাবেন সে Folder এর প্রথম ২টি Letter Type করে shift +Tab দিলে বাকিটা চলে আসবে )

## 4. আবার আগের Folder এ আসতে হলে (cd..) দিলে হয়ে যাবে। 

## 5. folder/dircetory -create করতে হলে - (mkdir < folder name >)

## 6. Folder delete করার জন্য ব্যবহার করা হয় -( rmdir /S  < folder name >) 

## 7. File - create  করার জন্য ব্যবহার করা হয় - (type null > fileName.txt )

## 8. File এ লেখা যুক্ত করতে চাইলে ব্যবহার করা হয় -( echo "লেখা থাকবে এখানে" file name )

## 9. File এ কিছু লিখেছি সেটা চেক করার জন্য ব্যবহার করা হয় -( type fileName )

## 10. File delete করার জন্য ব্যবহার করা হয় - (del file name )
